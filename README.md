# 🧠 AI Image Captioning with BLIP

## 🚀 Overview
This is a Generative AI project that generates captions for images using the BLIP model.

You can upload an image, and the model will generate a simple descriptive caption.

---

## 🔥 Features
- Upload image and get caption
- Uses BLIP pretrained model
- Built using Transformers and Gradio

---

## 🧠 Tech Stack
- Python
- PyTorch
- Transformers
- Gradio
- Pillow

---

## ⚙️ How It Works

1. Image is uploaded  
2. Image is processed using BLIP processor  
3. Model generates caption  
4. Caption is displayed  

---

## ▶️ Run the Project

Open the notebook:


Run all cells step by step.
